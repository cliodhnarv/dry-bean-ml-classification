# Dataset

This project uses the Dry Bean Dataset from the UCI Machine Learning Repository.

The dataset contains morphological measurements extracted from images of dry beans belonging to seven different varieties.

## Source

UCI Machine Learning Repository  
Dry Bean Dataset  
DOI: 10.24432/C50S4B

## Dataset Size

- 13,611 records
- 16 numerical predictor features
- 1 target variable (`Class`)
- 7 bean varieties
